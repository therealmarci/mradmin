# Überblick

**Der Werkzeugkasten für dein Server-Team:** Wartungen mit Countdown, Tickets und Reports, Admin-Modus, Spieler-Werkzeuge, Ankündigungen, Staff-Chat - im Spiel über Menüs und vom Handy über eine eigene Weboberfläche. Außerdem verbindet MRadmin alle anderen MRtechnology-Plugins miteinander.

| Auf einen Blick | |
|---|---|
| Server | Paper 26.3 (oder ein Fork wie Purpur), Java 25 |
| Benötigt | nichts - LuckPerms empfohlen, Uptime Kuma, und LibertyBans optional (squaremap für die Karte installiert MRadmin selbst) |
| Sprachen | Deutsch, Englisch - jeder Spieler automatisch in der Sprache seines Minecraft-Clients |
| Status | stabil (1.x) |

## Was kann MRadmin?
- **Wartungsarbeiten:** Während einer Wartung kommt nur das Team auf den Server. Geplante Wartungen kommen auf Wunsch live aus **Uptime Kuma**, vorher läuft eine **Bossbar mit Countdown**. → [Wartungsarbeiten](wartung.md)
- **Tickets & Reports:** Spieler melden Regelverstöße, Bugs und Fragen mit `/report` über ein Menü. Das Team antwortet im Spiel oder im Web - wie in einem Chat. → [Für Spieler](report.md), [fürs Team](tickets.md)
- **Admin-Modus:** Creative und ein Menü-Item. Beim Beenden ist alles wieder exakt wie vorher - Inventar, XP, Leben, Position. → [Dashboard & Admin-Modus](dashboard.md)
- **Spieler-Werkzeuge:** hinteleportieren, herholen, Inventar und Enderchest ansehen, einfrieren, kicken.
- **Ankündigungen** auf dem Bildschirm aller Spieler, mit Vorlagen (z.B. fürs Restart-Script) und auf Wunsch im Community-Discord. → [Ankündigungen](ankuendigungen.md)
- **Admin-Dashboard** mit Live-Kacheln, **Serverzustand** und **Staff-Chat**.
- **Weboberfläche** fürs Handy: Tickets, Spieler, Serverzustand, Wartungen, Push-Benachrichtigungen - mit 2FA und Passkeys. → [Weboberfläche](/docs/WEBOBERFLAECHE.md)
- **Spielerseite im Web (`/web`):** Jeder Spieler bekommt seine eigene Seite - eigene Tickets, Ranglisten und alles, was die anderen Plugins anbieten. → [Spielerseite](spielerseite.md)
- **Karte** auf der Spielerseite mit den Ebenen der anderen Plugins - squaremap rendert sie, MRadmin installiert, aktualisiert und richtet es selbst ein. → [Karte](karte.md)
- **Plugins, Updates & Einstellungen:** alle MRtechnology-Plugins im Web einstellen, aktualisieren, installieren, den Server mit Countdown neu starten. → [Plugins & Updates](plugins.md)
- **Discord-Logs**, **Update-Prüfung**, eine Permission für jede Funktion, jede Funktion einzeln abschaltbar.
